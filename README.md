# Personal Portfolio Website

##  About the Project
This is a personal portfolio website that showcases my personal information, skills, and different sections such as about me, projects, and contact information.

The website is built using HTML, CSS, and JavaScript, and uses Font Awesome icons for better visual presentation.

## 🚀 Live Demo
You can view the live version of the project here:

https://nxd909.github.io/Web-Dev/

##  Project Features
- Dark and light mode
- Multiple content sections  
- Responsive design  
- Icons integration using Font Awesome  
- Clean and simple UI  

##  Technologies Used
- HTML  
- CSS  
- JavaScript  
- Font Awesome Icons  

## 💡 Notes
- The project uses CDN version of Font Awesome.
- No additional installation is required.
